## 🚀 เริ่มเกมใน 5 นาที

**วิธีเล่นเดี่ยว (ไม่ต้องใช้เน็ต):**
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome / Edge / Firefox) → กดปุ่ม **"▶ เริ่มเล่นเดี่ยว"** → เท่านี้ก็เล่นได้เลย ไม่มีการติดตั้ง ไม่มี dependency ใดๆ ทั้งสิ้น

**วิธีเล่นออนไลน์ (ต้องมีเซิร์ฟเวอร์):**
เปิดหน้าเกมผ่าน URL ของเซิร์ฟเวอร์ เช่น `http://103.253.75.161:3109/` → กด **"🌐 สร้างห้องออนไลน์"** → ตั้งชื่อ → กด "สร้างห้อง" → จะได้รหัสห้อง 4 ตัว (เช่น `ERPF`) ส่งรหัสให้เพื่อน → เพื่อนกด "🔑 เข้าห้อง (มีรหัส)" แล้วกรอกรหัส

> 💡 **เซฟอัตโนมัติ**: เกมเดี่ยวเซฟลง localStorage ของเบราว์เซอร์เอง (กด `P` เซฟทันทีได้) — ส่วนห้องออนไลน์โลกถูกเก็บบนเซิร์ฟเวอร์ ปิดเบราว์เซอร์ไปโลกก็ยังอยู่

## ✋ ระบบมือถือของ (Hand Slots) และ Hotbar

เกมใช้ระบบ **"ถือของในมือ 8 ช่อง"** (คล้าย hotbar ของ Minecraft):

- Hotbar 1–8 คือ **ช่องมือ** — แต่ละช่องถือไอเทมได้ 1 ชนิด (`block:8` = อิฐ, `stone_sword` = ดาบหิน, `bread` = ขนมปัง)
- **บล็อกที่ทุบได้จะเข้ามืออัตโนมัติ** เมื่อมีช่องว่าง (เฉพาะบล็อกเท่านั้น)
- **อาหาร/ดาบ/เครื่องมือต้องถือเอง**: กด `E` → คลิกซ้ายที่ไอเทมในคลัง → ของขึ้น hotbar ทันที
- ตัวเลข `x3` บนช่อง = จำนวนที่มีในคลัง; โหมดบินแสดง `∞` (วางฟรี)
- ถืออาหารแล้ว**คลิกขวา = กิน** / ถือบล็อกแล้ว**คลิกขวา = วาง** / คลิกซ้ายใส่ม็อบ = ตีด้วยดาเมจของของที่ถือ

> ⚠️ ถ้าช่องมือว่างแล้วคลิกขวา เกมจะเตือน "กด E แล้วคลิกซ้ายของเพื่อถือ"

## ❤️ วงจรเซอร์ไววัล

| ค่า | ค่าเริ่มต้น | ผลเมื่อหมด |
|---|---|---|
| ❤️ HP | 20 (10 หัวใจ) | ตาย → เกิดใหม่ที่จุดสปอว์น |
| 🍗 ความหิว | 20 (10 จาน) | หิว = 0 นานๆ เริ่มเสีย HP (โหมดเดิน) |
| 🫧 อากาศ (ในน้ำ) | 10 | หมด = จมน้ำ เสีย HP 1/วินาที |

**อาหารทั้งหมด** (กินด้วยคลิกขวาขณะถือ หรือคลิกขวาในคลังของ):

| อาหาร | ความหิวที่ได้คืน | ได้มาจาก |
|---|---|---|
| 🥖 ขนมปัง (bread) | +4 | คราฟต์ / กล่องบ้านเก่า |
| 🍖 หมูดิบ (pork) | +3 | ฆ่าหมู |
| 🍖 หมูสุก (cooked_pork) | +5 | คราฟต์: หมูดิบ + ถ่าน |
| 🥩 เนื้อเน่า (rotten_flesh) | +1 (กินได้แต่คุ้มน้อย) | ฆ่าซอมบี้ |

**ความเสียหายจากสภาพแวดล้อม**: ตกจากที่สูง (เกิน 3 บล็อกเริ่มเจ็บ), จมน้ำ, ถูกม็อบโจมตี, ความหิวขัดสน — โหมดบินปลอดภัยจากทั้งหมด

## ⚔️ การต่อสู้และม็อบ

**ดาเมจตามของที่ถือ** (คลิกซ้ายใส่ม็อบใต้เป้าเล็ง):

| ของในมือ | ดาเมจ/ครั้ง |
|---|---|
| หมัดเปล่า / ของอื่นๆ | 1 |
| 🗡️ ดาบไม้ (wooden_sword) | 3 |
| ⚔️ ดาบหิน (stone_sword) | 4 |
| ดาบจาก mod (`*_sword`) | 4 (อนุสัญญาชื่อ) |

**ม็อบในเกม:**
- 🐷 **หมู** / 🐮 **วัว** — ไม่รังควาน ฆ่าได้เนื้อ/หนัง
- 🧟 **ซอมบี้** — มืดคืนเท่านั้น เดินเข้าหาผู้เล่น ตีสู้ได้ ดรอปเนื้อเน่า
- 💥 **ครีปเปอร์** — มืดคืน เข้าใกล้แล้ว**ระเบิด** (ทุบบล็อกรอบตัว) ดรอปดินปืน

เคล็ดลับ: ทุบบล็อกใกล้ม็อบปีศาจจะทำให้มันเล็งเป้ามาที่เรา — ระวังตอนขุดหาแร่ตอนกลางคืน! กลางวันม็อบปีศาจจะหายไป

## 🌊 น้ำ ว่ายน้ำ และการจมน้ำ

- **ลงน้ำจากที่สูง**: ไม่เจ็บ (น้ำยกเลิก fall damage) + เสียง splash + อนุภาคน้ำ
- **ในน้ำ**: เคลื่อนที่ช้าลง (×0.6), จมลงช้าๆ, กด `Space` ว่ายขึ้น
- **หัวอยู่ใต้น้ำ**: ฟองอากาศ (🫧×10) ลด 1 ฟองทุก ~1.4 วินาที — หมดแล้วเสีย HP **1/วินาที**
- **โผล่หัวพ้นน้ำ**: อากาศเต็มทันที
- น้ำในโลกส่วนใหญ่เป็นแอ่งตื้น 1 บล็อก — อยากดำลึกให้ขุดพื้นทรายใต้น้ำเพิ่มความลึก
- บล็อกน้ำไม่ใช่ของแข็ง — เดินทะลุได้ และยังวางบล็อกทับน้ำได้

## ⛏️ การขุด คราฟต์ และสูตรทั้งหมด

**ทุบอะไรได้อะไร** (ตัวอย่างสำคัญ): หญ้า/ดิน→ดิน, หิน→หินกรวด (cobble), ไม้→ไม้, ใบไม้→(นานๆ ครั้ง ลูกไม้), แร่ถ่าน/เหล็ก/ทอง/เพชร→แร่นั้นๆ, บล็อกแร่ต้องใช้พลั่ว

### คราฟต์ 2×2 (กด `C` — ทำได้ทุกที่)

| ผลลัพธ์ | ส่วนผสม |
|---|---|
| ไม้แปรรูป ×4 | ไม้ ×1 |
| ไม้ขีด (stick) ×4 | ไม้แปรรูป ×2 |
| คบไฟ (torch) ×4 | ไม้ขีด ×1 + ถ่าน ×1 |
| โต๊ะคราฟต์ ×1 | ไม้แปรรูป ×4 |
| กระจก ×1 | ทราย ×1 + ถ่าน ×1 |
| อิฐ ×4 | หินกรวด ×4 |
| พลั่วไม้ | ไม้แปรรูป ×3 + ไม้ขีด ×2 |
| พลั่วหิน | หินกรวด ×3 + ไม้ขีด ×2 |
| พลั่วเหล็ก | เหล็กแท่ง ×3 + ไม้ขีด ×2 |
| ดาบไม้ | ไม้แปรรูป ×2 + ไม้ขีด ×1 |
| ดาบหิน | หินกรวด ×2 + ไม้ขีด ×1 |
| หมูสุก ×1 | หมูดิบ ×1 + ถ่าน ×1 |

### คราฟต์ 3×3 (วางโต๊ะคราฟต์แล้ว Shift+คลิกขวา)

| ผลลัพธ์ | รูปแบบ (3×3) |
|---|---|
| หีบ (chest) | ไม้แปรรูปครบ 9 ช่อง |
| เตา (furnace) | หินกรวดล้อมรอบ ช่องกลางว่าง |
| ประตูไม้ ×3 | ไม้แปรรูป 2 คอลัมน์ซ้าย-ขวา (6 ช่อง) |
| กระจก | ทราย 4 มุม + ถ่านกลาง |
| อิฐ ×4 | หิน 2×2 มุมซ้ายบน |

## 🪽 โหมดบิน (ครีเอทีฟ)

กด `F` สลับโหมด:

- **เปิดบิน**: ช่องมือว่างถูกเติมด้วยพาเลทต์บล็อก 8 ชนิด **อัตโนมัติ** (แสดง `∞`)
- **วางบล็อกฟรี** ไม่หักคลัง, ไม่หิว, ไม่เจ็บตก, เวลาในเกมเดินเร็วขึ้น 6 เท่า
- `Space` บินขึ้น / `Shift` บินลง
- ปิดบิน (กด `F` อีกครั้ง) = กลับโหมดเซอร์ไววัลเต็มรูปแบบ

## 📦 หีบ (Chest) 27 ช่อง

1. คราฟต์หีบ (ต้องมีโต๊ะคราฟต์) → วางลงพื้น
2. **Shift+คลิกขวา**ที่หีบเพื่อเปิด → ลากของจากคลังเข้า/ออก 27 ช่อง
3. ของในหีบถูกเซฟไปกับโลก — **ทุบหีบ = ของทั้งหีบกลับเข้าคลังอัตโนมัติ** (ไม่หล่นหาย)
4. ในห้องออนไลน์ ทุกคนแก้หีบร่วมกันได้แบบเรียลไทม์ (sync ทันที)

## 🧩 Block Code Editor — สอนเขียนโปรแกรมบอท

กดปุ่ม **"🧩 Code Editor"** ที่หน้าเมนู (หรือ `T` → `/edit` ในเกม) เพื่อเขียนโปรแกรมแบบ **ลากบล็อกคำสั่งมาต่อกัน** (สไตล์ Scratch)

### แนวคิดหลัก

- โปรแกรม = **สคริปต์** หลายอัน แต่ละอันเริ่มจาก "หัว" (event) แล้วต่อคำสั่งเป็นเส้น
- พิกัด x/y/z ในคำสั่งเป็น **สัมพัทธ์กับตำแหน่งผู้เล่นตอนกด Run**: `(0,0,0)` = ตำแหน่งเท้าผู้เล่น, `+y` = ขึ้นบน
- กด **▶ Run** → บอท (เอเจนต์) เกิดที่ตำแหน่งผู้เล่นแล้วทำตามโปรแกรมทีละขั้นแบบเห็นภาพ
- มี **↩ Undo**, 📤 Export (แชร์เป็น JSON), 📥 Import, 🗑 ล้างทั้งหมด

### บล็อกคำสั่งทั้งหมด

**📢 เหตุการณ์ (หัวสคริปต์ — อันละ 1 ต่อสคริปต์)**

| บล็อก | ทำงานเมื่อ |
|---|---|
| 🏁 เมื่อเริ่ม | กด Run (เริ่มทันที) |
| 💬 เมื่อพูด `command` | มีคนพิมพ์ `/<command>` ในแชท (ค่าเริ่มต้น `/go`) |
| ⌨ เมื่อกด `key` | กดปุ่มที่กำหนด (w/a/s/d/space/ลูกศร) |

**🚶 เคลื่อนไหว**

| บล็อก | พารามิเตอร์ |
|---|---|
| 🚶 เดิน | ทิศ (หน้า/หลัง/ซ้าย/ขวา) × จำนวนก้าว |
| 🔄 หมุน | องศา (-360 ถึง 360) |
| 🦘 กระโดด | — |
| ✈ บินขึ้น / ⬇ บินลง | ความสูง 1–20 |
| 🌀 วาร์ป | ระยะ 1–50 (ไปข้างหน้าตามทิศที่หัน) |

**🎬 แอคชั่น**

| บล็อก | พารามิเตอร์ | หมายเหตุ |
|---|---|---|
| ⛏ ทุบ | — | ทุบบล็อกข้างหน้า |
| 🧱 วาง | ชนิดบล็อก | วางข้างหน้า |
| 💬 พูด | ข้อความ | โชว์ป้ายคำพูดเหนือบอท |
| 🌀 เกิดที่ (สัมพัทธ์) | x, y, z | วาร์ปบอทไปพิกัดสัมพัทธ์ |
| 🎯 วางที่ (สัมพัทธ์) | x, y, z, บล็อก | วางบล็อกที่จุดระบุ |
| 🧱 เติมพื้นที่ (fill) | x1,y1,z1 → x2,y2,z2, บล็อก | วางทั้งก้อนสี่เหลี่ยม |

**⚙ ควบคุม**

| บล็อก | หมายเหตุ |
|---|---|
| 🔁 วนซ้ำ (count) | ทำซ้ำบล็อกย่อยตามจำนวนครั้ง |
| ❓ ถ้า (เงื่อนไข) | เงื่อนไข: block_ahead / ground_below / is_day / is_night |
| 🔁 ทำซ้ำเมื่อ (while) | วนขณะเงื่อนไขจริง — เช่น "ทุบ+เดิน ขณะมีบล็อกข้างหน้า" = ระเบิดอุโมงค์ |
| ⏱ รอ (วินาที 0.1–10) | |

**💜 ตัวแปร**

| บล็อก | ใช้ทำอะไร |
|---|---|
| 💜 ตั้งค่า `name` = `value` | เก็บตัวเลข เช่นนับจำนวน |
| 💜 เปลี่ยน `name` += `delta` | เพิ่ม/ลดค่า |

### ตัวอย่างแรกใน 3 นาที

กดปุ่ม **"📝 ตัวอย่าง"** ใน editor แล้วกด Run — บอทจะทักทาย วางหญ้า 5 ก้อน เดินหน้า 5 กวาด แล้วบอก "เสร็จแล้ว!" จากนั้นลองแก้ count จาก 5 เป็น 10 ดู

**ตัวอย่างไอเดีย:**
- **ทางเดินยาว**: `เมื่อเริ่ม → วนซ้ำ 20 { วาง หิน → เดิน หน้า 1 }`
- **เสาไฟ**: `เมื่อเริ่ม → วางที่ (0,0,0) หิน → วางที่ (0,1,0) คบไฟ → ... สูงขึ้นเรื่อยๆ`
- **อุโมงค์อัตโนมัติ**: `เมื่อพูด "dig" → ทำซ้ำเมื่อ block_ahead { ทุบ → เดิน หน้า 1 }` แล้วพิมพ์ `/dig` ในแชท
- **เต้นรับเช้า**: `เมื่อกด space → หมุน 360 → กระโดด → พูด "อรุณสวัสดิ์!"`

## 🤖 AI Script Generator

กดปุ่ม **"🤖 AI"** ใน Code Editor แล้ว**พิมพ์ภาษาไทย**บอกความต้องการ เช่น:

```
สร้างบ้าน 5x5 จากอิฐ
หอคอยสูง 10 จากหิน
กำแพงยาว 20 ไม้
ขุดหลุม 5x5
สร้างสะพานยาว 15
```

- **โหมด local (default)**: ทำงานออฟไลน์ ไม่ใช้เน็ต — จับคีย์เวิร์ด + ตัวเลขจากประโยคแล้วสร้างสคริปต์ให้เอง
- **รองรับ 12 แพตเทิร์น**: 🏠 บ้าน, 🗼 หอคอย, 🧱 กำแพง, 🌉 สะพาน, ▦ พื้น/แท่น, 🔺 พีระมิด, 🏊 สระน้ำ, ⭕ วงกลม, ⛏ ขุดหลุม, 🚶 เดิน, 👋 ทักทาย, 🌳 ต้นไม้
- ระบุวัสดุได้: หญ้า ดิน หิน ทราย ไม้ ไม้แปรรูป หินก่อ อิฐ หิมะ กระจก ฟักทอง
- ระบุขนาดได้: `5x5`, `สูง 10`, `ยาว 20`, `รัศมี 7`
- **โหมด online (ตั้งค่าได้)**: เสียบ OpenAI-compatible API เพื่อให้ LLM แท้ๆ สร้างสคริปต์ (ใส่ key ของตัวเอง เก็บในเครื่อง)
- หลัง Generate → ดูผล → กด **"➕ เพิ่มเข้า workspace"** หรือ **"🔄 แทนที่ทั้งหมด"** → กด Run ได้เลย

> ✅ ผ่านการทดสอบจริง: prompt "สร้างบ้าน 5x5 จากอิฐ" → บอทสร้างบ้านอิฐ 44 ก้อน + หน้าต่างกระจกในโลกเกม

## 🌐 ออนไลน์: ห้อง โค้ด โฮสต์ย้าย โลกค้างไว้

### สร้าง/เข้าห้อง
- **สร้างห้อง**: ตั้งชื่อ → ได้รหัส 4 ตัวอักษร → แชร์ให้เพื่อน (สูงสุด 8 คน/ห้อง)
- **เข้าห้อง**: กรอกรหัส → โหลดโลกจาก host อัตโนมัติ (เข้ากลางเกมได้ เห็นทุกอย่างที่สร้างไว้)

### ซิงก์แบบเรียลไทม์
- ตำแหน่ง/มุม/HP ของทุกคน (10 ครั้ง/วินาที), ทุบ-วางบล็อก, แชท, หีบร่วม, เห็นบอท+ป้ายชื่อของกันและกัน

### 🏰 โลกค้างไว้บนเซิร์ฟเวอร์ (Persistent Worlds)
- โลกของห้องถูก**เซฟไว้บนเซิร์ฟเวอร์ทุก 30 วินาที** (อัตโนมัติ เฉพาะตอน host อยู่)
- **host ออกจากเกมได้เลย** — ผู้เล่นคนแรกที่เหลืออยู่ได้เป็น host คนใหม่อัตโนมัติ (host migration) โลกวิ่งต่อไม่มีสะดุด
- ทุกคนออกหมด โลกก็ยังอยู่ — กลับมาเปิดใหม่ด้วยรหัสเดิมได้ (ของในหีบครบ)
- ปุ่ม **"🌍 โลกที่บันทึก"** ที่เมนู = เบราว์เซอร์รายการโลกบนเซิร์ฟเวอร์ (ชื่อ/ขนาด/จำนวนบล็อก/เวลาล่าสุด) เข้าชมได้เลย

> ⚠️ เกมเดี่ยวจะ**ไม่**ทับเซฟส่วนตัวด้วยโลกออนไลน์ — ระบบแยกชัดเจน

## ❓ คำถามที่พบบ่อย (FAQ)

**Q: เปิด index.html แล้วเมาส์ไม่ยอมหมุนกล้อง?**
A: คลิกที่หน้าจอเกม 1 ครั้งเพื่อ "ล็อคเมาส์" (pointer lock) — ถ้าเบราว์เซอร์บล็อค จะมีข้อความเตือน ให้คลิกอีกครั้ง

**Q: เซฟหายไหมถ้าปิดเบราว์เซอร์?**
A: เกมเดี่ยวเซฟอยู่ใน localStorage ของเบราว์เซอร์นั้นๆ (อย่าใช่โหมดไม่บันทึก) / ห้องออนไลน์โลกอยู่บนเซิร์ฟเวอร์ตลอด

**Q: ทำไมวางบล็อกไม่ได้?**
A: เช็ค 3 อย่าง — (1) ช่องมือต้องถือบล็อก (ไม่ใช่ว่าง/อาหาร/ดาบ) (2) โหมดเดินต้องมีของในคลัง (กด E ดู) (3) ตำแหน่งวางต้องไม่ทับตัวเอง

**Q: บอทรันแล้วไม่วางบล็อก?**
A: คำสั่ง "วาง" วางข้างหน้าบอท — ถ้าช่องข้างหน้ามีบล็อกอยู่แล้วจะข้าม (เหมือนมือจริง) ให้เริ่มด้วย "ทุบ" หรือใช้ "วางที่ (สัมพัทธ์)" ระบุพิกัดแทน

**Q: พิกัดสัมพัทธ์คืออะไร?**
A: (0,0,0) คือที่ยืนของ**ผู้เล่นตอนกด Run** — ลองสร้างบ้านด้วย fill `(0,0,0)→(4,2,4)` จะเห็นบ้านโผล่คร่อมตัวเอง

**Q: เล่นมือถือได้จริงไหม?**
A: ได้ — จอยสติ๊ก+ปุ่มรองรับเต็มรูปแบบ และ PWA ติดหน้าจอบ้านได้

**Q: อยากเล่นกับเพื่อนแต่ไม่มีเซิร์ฟเวอร์?**
A: รันเองได้ใน 1 บรรทัด: `node multiplayer/server/server.js` แล้วแชร์ IP:3109 (ดู [docs/DEPLOY.md](DEPLOY.md))
